# Project Instructions

- When adding or updating files in `supabase/migrations`, always remind the user that this project does not auto-apply migrations to Supabase. Include the SQL that needs to be run or clearly tell the user which migration file to apply in the Supabase SQL Editor.
- Treat mobile responsiveness and fast site performance as primary priorities for every change. Consider mobile layout, interaction speed, query efficiency, bundle impact, and image/loading behavior before finishing implementation.
- Consider UX psychology on every user-facing change: visual familiarity, trust signals, cognitive load, typography, spacing, perceived speed, action clarity, and subtle bounce risks. Avoid designs that feel unfamiliar, overwhelming, low-trust, or visually heavy on mobile.
- In Go Pair PH marketing copy, default to "shoes" or "running shoes" instead of repeatedly saying "pair." Filipino runners generally find those terms more natural. Use "pair" only when it genuinely fits the sentence, such as "favorite pair" or "wrong-size pair," and avoid repetitive wording that sounds AI-generated.
