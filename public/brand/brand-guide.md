# Go Pair PH Social Brand Guide

## Positioning

Go Pair PH is a focused marketplace for people buying and selling running shoes in Central Luzon and NCR. Facebook remains useful for reach; Go Pair PH gives sellers one organized listing they can reuse wherever they sell.

## Voice

- Helpful, concise, trustworthy, and local.
- Sound like one Filipino runner talking to another.
- Use natural English with restrained Filipino humor when appropriate.
- Default to "shoes" or "running shoes." Use "pair" only when it genuinely sounds natural.
- Never invent users, listings, transactions, demand, popularity, urgency, or endorsements.

## Visual System

- Dark navy foundation: `#061826`.
- Primary teal: `#0d9488`.
- Highlight teal: `#2dd4bf`.
- Primary text: `#f8fafc`.
- Secondary text: `#cbd5e1`.
- Premium editorial marketplace composition, not a generic advertisement.
- High contrast, refined spacing, crisp framing, and mobile-readable type.
- Use realistic generic running shoes without recognizable product logos or copied designs.
- Avoid social-platform branding, badges, watermarks, collages, and visual clutter.

## Official Logo

The canonical raster mark is `public/brand/gopairph-logo-mark-1024.png`.

Never ask an image model to recreate, redraw, spell, or reinterpret the logo. Generate social artwork with a clean reserved footer, then apply the official logo and footer using `scripts/brand-social-image.cjs`.

If the official logo asset is unavailable, do not invent a replacement.
