# Project Instructions

- When adding or updating files in `supabase/migrations`, always remind the user that this project does not auto-apply migrations to Supabase. Include the SQL that needs to be run or clearly tell the user which migration file to apply in the Supabase SQL Editor.
- Treat mobile responsiveness and fast site performance as primary priorities for every change. Consider mobile layout, interaction speed, query efficiency, bundle impact, and image/loading behavior before finishing implementation.
